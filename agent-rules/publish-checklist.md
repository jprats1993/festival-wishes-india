# Publish Checklist

## Content

- [ ] Festival date and regional details verified.
- [ ] Hindi text reviewed by a native speaker OR by reviewer-agent with owner spot-check noted.
- [ ] English grammar reviewed.
- [ ] Hinglish spelling is consistent and natural.
- [ ] No wish is a near-duplicate of another published wish.
- [ ] No copied or unattributed material is present.
- [ ] Page has useful introductory or contextual text.

## SEO

- [ ] URL is stable, descriptive, and language-specific.
- [ ] One clear H1 and logical headings.
- [ ] Title and meta description match the page.
- [ ] Canonical URL is correct.
- [ ] Language alternate links are correct where applicable.
- [ ] Thin filter/search pages are `noindex`.
- [ ] Page is linked from a relevant hub.
- [ ] Sitemap and robots output are valid.

## Images and sharing

- [ ] Asset provenance is recorded.
- [ ] Image text exactly matches approved text.
- [ ] Alt text describes the image and its purpose.
- [ ] Download works on mobile.
- [ ] Native share is tested where supported.
- [ ] WhatsApp text-link fallback works.
- [ ] Download-and-attach fallback is visible when file sharing is unavailable.

## Monetization and compliance

- [ ] Privacy, contact, about, and disclaimer pages are live.
- [ ] Affiliate disclosure is present on affiliate pages.
- [ ] Ads are not enabled until the site is approved and complete.
- [ ] Ad slots do not resemble download or share controls.
- [ ] `ads.txt` is updated when required.

## Release

- [ ] Preview build reviewed by owner or assigned reviewer.
- [ ] Lighthouse/mobile smoke test passed.
- [ ] No broken links or missing assets.
- [ ] Analytics events verified.
- [ ] Rollback target is known.
- [ ] Production deployment recorded in the changelog.
